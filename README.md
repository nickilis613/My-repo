

A static, offline-friendly reading interface containing only the professionally edited Chapters 1–300.

The site supports chapter search and navigation, night and paper themes, adjustable type size, keyboard navigation (`[` and `]`), and automatic reading-position memory.

## Run locally

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173/`.

## GitHub Pages

The repository contains plain static files and can be published directly from the root of the default branch.
